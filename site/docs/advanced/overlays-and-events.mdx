# Overlays & Events

Overlays and the presenter console communicate through a central, typed event bus.

## Overlays

Overlays attach interactive UI widgets over the stage canvas (such as laser pointers, drawing tools, and navigation buttons):

```typescript
import { Stage, NavigationOverlay, LaserPointer } from "stageroutine";

const stage = new Stage();
stage.overlay(LaserPointer());
stage.overlay(NavigationOverlay());
```

### Built-in Overlays
- **`LaserPointer()`**: WebGL glowing laser pointer. Toggle with the `P` key (or `Esc` to exit).
- **`NavigationOverlay()`**: Next/Previous step buttons, scene jumpers, and pointer toggle that appear on hover near the screen bottom.

## Event System

All communication between the stage, overlays, keyboard shortcuts, and the presenter console flows through a single typed event bus using `req:` (requests) and `evt:` (notifications):

| Domain | Requests (`req:*`) | Notifications (`evt:*`) |
|---|---|---|
| `nav:` | `req:nav:nextStep`, `req:nav:prevStep`, `req:nav:nextScene`, `req:nav:prevScene`, `req:nav:gotoStep`, `req:nav:gotoScene` | `evt:nav:stepChanged`, `evt:nav:sceneChanged` |
| `stage:` | `req:stage:requestState` | `evt:stage:resized`, `evt:stage:stateChanged` |
| `pointer:` | `req:pointer:setState` | `evt:pointer:stateChanged` |

### Listening and Emitting

```typescript
// Listen for navigation step changes
stage.on("evt:nav:stepChanged", ({ index, total, scene }) => {
  console.log(`Step ${index + 1} of ${total} (${scene})`);
});

// Emit navigation requests programmatically
stage.emit("req:nav:nextStep");

// Toggle pointer mode
stage.emit("req:pointer:setState", { active: true });
```

### Dual-Screen BroadcastChannel
The event bus transparently bridges across browser windows using the browser's native `BroadcastChannel`. Opening `presenter.html` on a second display immediately connects to the stage without network sockets or servers.
