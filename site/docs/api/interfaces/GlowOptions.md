# Interface: GlowOptions

Configuration options for the glow decorator.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="duration"></a> `duration?` | `number` | Animation cycle duration in seconds if pulse is enabled (default: 4). |
| <a id="pulse"></a> `pulse?` | `boolean` | Whether the glow breathes/animates (default: true). |
