# Interface: GradientOptions

Configuration options for the linear gradient text decorator.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="angle"></a> `angle?` | `number` | Gradient angle in degrees (default: 90). |
| <a id="colors"></a> `colors?` | `string`[] | Array of CSS color stops for the gradient. |
| <a id="duration"></a> `duration?` | `number` | Animation cycle duration in seconds if flow is enabled (default: 7). |
| <a id="flow"></a> `flow?` | `boolean` | Whether the gradient should animate/flow continuously (default: true). |
