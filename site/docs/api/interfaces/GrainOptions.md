# Interface: GrainOptions

Configuration options for the film grain texture decorator.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="animated"></a> `animated?` | `boolean` | Whether the grain subtly flickers/moves (default: true). |
| <a id="granularity"></a> `granularity?` | `number` | Granularity scale factor in pixels (default: 1. Higher numbers produce larger, chunkier grain blocks). |
| <a id="opacity"></a> `opacity?` | `number` | Film grain opacity from 0 to 1 (default: 0.12). |
| <a id="size"></a> `size?` | `number` | Noise tile size in pixels (default: 512). |
