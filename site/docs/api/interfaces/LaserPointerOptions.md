# Interface: LaserPointerOptions

Configuration options for the laser pointer plugin.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="color"></a> `color?` | `string` | Base laser beam color in RGB hex. Defaults to neon laser ruby ('#ff0055'). |
| <a id="idletimeoutms"></a> `idleTimeoutMs?` | `number` | Inactivity delay before the pointer sleeps. Defaults to 2000ms. |
| <a id="traildurationms"></a> `trailDurationMs?` | `number` | Trail persistence in milliseconds. Defaults to 160ms. |
