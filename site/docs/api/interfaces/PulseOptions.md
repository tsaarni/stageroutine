# Interface: PulseOptions

Options for triggering glowing packet animations along a connector.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="color"></a> `color?` | `string` | Color of the glowing particle (defaults to connector stroke color). |
| <a id="duration"></a> `duration?` | `number` | Duration of the particle traversal in seconds (default: 0.6s). |
| <a id="size"></a> `size?` | `number` | Diameter of the particle in virtual canvas pixels (default: 8px). |
