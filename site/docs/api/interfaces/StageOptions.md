# Interface: StageOptions

Options for initializing the Stage presentation director.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="defaultduration"></a> `defaultDuration?` | `number` | Default transition duration in seconds (default: `0.6`). |
| <a id="height"></a> `height?` | `number` | Virtual stage height in pixels (default: `1080`). |
| <a id="target"></a> `target?` | `string` \| `HTMLElement` | Target HTML container or CSS selector to mount into. |
| <a id="theme"></a> `theme?` | [`ThemeConfig`](ThemeConfig.md) | Initial theme color overrides. |
| <a id="width"></a> `width?` | `number` | Virtual stage width in pixels (default: `1920`). |
