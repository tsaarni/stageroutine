# Interface: VignetteOptions

Configuration options for the radial dark vignette decorator.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="color"></a> `color?` | `string` | Vignette color (default: "#09090b"). |
| <a id="opacity"></a> `opacity?` | `number` | Center darkness opacity from 0 to 1 (default: 0.9). |
| <a id="shape"></a> `shape?` | `string` | Custom radial gradient falloff shape (default: "ellipse 55% 55% at 50% 50%"). |
