# Layout

The `layout` object calculates element coordinates and dimensions automatically.
For details on stage units and screen coordinates, see [Coordinates](./coordinates).

![StageRoutine Layout Modes](/img/layout-modes.svg)

## Vertical Stacks

Use `layout.vstack` to arrange elements in a column from top to bottom.

```typescript
import { layout } from "stageroutine";

layout.vstack([title, subtitle, description], {
  x: "center", // Horizontal position or "center" (default: 10)
  y: 20,       // Vertical start position (default: 15)
  gap: 3,      // Space between elements (default: 3)
});
```

## Horizontal Stacks

Use `layout.hstack` to arrange elements in a row from left to right.

```typescript
layout.hstack([card1, card2, card3], {
  x: 10,  // Horizontal start position (default: 10)
  y: 35,  // Vertical position or "center" (default: 15)
  gap: 4, // Space between elements (default: 4)
});
```

## Nested Stacks

You can nest arrays inside `layout.hstack` and `layout.vstack`.
An inner array switches the layout direction for that slot.

- In `layout.hstack`, an inner array stacks elements vertically into a column.
- In `layout.vstack`, an inner array stacks elements horizontally into a row.

![StageRoutine Nested Stacks](/img/nested-stacks.svg)

```typescript
// Two columns side by side
layout.hstack([
  [heading, body], // First column (stacked vertically)
  codePanel,       // Second column
], {
  gap: 4,
});

// A row nested inside a vertical stack
layout.vstack([
  header,
  [card1, card2],  // Nested row (arranged horizontally)
  footer,
], {
  gap: 3,
});
```

Nested slots divide available space equally by default.
To set custom sizes, pass an array to `width` or `height`:

```typescript
// 40% for column 1, 50% for column 2
layout.hstack([[heading, body], codePanel], {
  width: [40, 50],
});
```

## Grid Layouts

Use `layout.grid` to align elements in rows and columns at the same time.
Pass a two-dimensional array of rows.
Use `null` for empty cells.

```typescript
layout.grid([
  [clientApp,   apiGateway,   null],
  [authService, dbService,    redisCache],
], {
  x: "center", // Horizontal position or "center" (default: 10)
  y: 25,       // Vertical start position (default: 15)
  gapX: 4,     // Space between columns (default: 4)
  gapY: 4,     // Space between rows (default: 4)
});
```

## Relative Positioning

Use relative helpers to position elements relative to a target element.
You can pass a single element (`item`) or an array of elements (`[item1, item2]`), with optional configuration for gap, alignment, and animation.
If omitted, `gap` defaults to `2` percentage units.

```typescript
// Place a single element below a target (default gap: 2)
layout.below(caption, chart);

// Place multiple elements below a target with custom gap and animation
layout.below([item1, item2, item3], title, {
  gap: 3,          // Space between elements (default: 2)
  align: "start",  // "start" (default), "center", or "end"
  animate: (coord, el, index) =>
    to(coord).duration(0.6).delay(index * 0.1),
});

// Place details to the right of card
layout.rightOf(details, card, { gap: 4, align: "center" });
```

Available helpers:
- `layout.below(elements, target, options?)`: positions elements below the target.
- `layout.above(elements, target, options?)`: positions elements above the target.
- `layout.rightOf(elements, target, options?)`: positions elements to the right of the target.
- `layout.leftOf(elements, target, options?)`: positions elements to the left of the target.

Options:
- `gap`: Spacing between elements and the target in percentage units (default: `2`).
- `align`: Perpendicular alignment: `"start"` (default), `"center"`, or `"end"`.
- `stack`: When passing multiple elements, whether they chain sequentially (default: `true`). Set `false` to move multiple elements without chaining.
- `animate`: Position transition builder callback or `true`.

## Circular Layouts

Use `layout.circle` to place elements in a circle around a center point.

```typescript
layout.circle([node1, node2, node3, node4], {
  center: [50, 50], // Center point [x, y] or element (default: [50, 50])
  radius: 18,       // Distance from center (default: 20)
});
```

## Divider Lines

Add `rule: true` to draw divider lines in gutters between elements:

```typescript
const rules = layout.hstack([col1, col2], { rule: true });
stage.scene("Overview").with(col1, col2, ...rules);
```

You can also pass an options object to customize `color`, `thickness`, `borderStyle`, or `bracket`:

```typescript
layout.hstack([col1, col2], {
  rule: { borderStyle: "dashed", bracket: true },
});
```

## Animating Layouts

By default, layouts update positions immediately.
To animate elements into their new positions, pass a callback to `animate`.

The layout calculates the target `x` and `y` coordinates, then calls your callback for each axis to build the transition.

```typescript
layout.vstack([card1, card2, card3], {
  animate: (coord, el, index) =>
    to(coord).duration(0.8).ease("quartOut").delay(index * 0.1),
});

stage.scene("Details").with(card1, card2, card3);
```

Callback parameters:
- `coord`: Target coordinate (`x` or `y`) calculated by the layout.
- `el`: Element being positioned.
- `index`: Element index in the layout, useful for staggered delays.

To use default timing without custom easing or delay, pass `animate: true`.
