# Visual Effects

Enhance elements and the stage with built-in decorators, WebGL backgrounds, and icons.

## Decorators

Decorators add visual effects to elements via `.decorate()` without modifying their positioning or layout.

```typescript
import { Title, CodeBlock, gradient, glow, rule, bracket, typewriter } from "stageroutine";

// Apply visual styles
const title = Title("StageRoutine").decorate(gradient()).decorate(glow());

// Add technical divider rules and brackets to code blocks
const terminal = CodeBlock(["pnpm dev"]).decorate(rule()).decorate(bracket());
```

### Built-in Decorators
- `gradient()`: Text or container gradient fills
- `glow()`: Neon glowing drop-shadows
- `rule()`: Accent rule / divider line (straight, dashed, or bracketed)
- `bracket()`: Technical framing brackets
- `typewriter()`: Animated typewriter text reveal

## Backgrounds

Backgrounds provide procedural canvas or WebGL backdrops beneath the stage:

```typescript
import { Stage, AsciiFluid, Starfield, GradientFluid, vignette } from "stageroutine";

const stage = new Stage().background(
  AsciiFluid().decorate(vignette())
);
```

### Built-in Backgrounds
- `AsciiFluid()`: WebGL fluid simulation rendered with ASCII characters
- `GradientFluid()`: Smooth colorful fluid simulation
- `Starfield()`: Procedural 3D perspective stars
- `CSSBackground()`: Gradients and solid colors
