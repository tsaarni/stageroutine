# BrowserWindow

An interactive webpage inside a browser frame.

The page runs in an iframe with its own document and JavaScript context.

<DemoFrame src="/stageroutine/previews/browser-window.html" />

```typescript preview="browser-window.html"
// hide-start
import { Stage } from "stageroutine";
const stage = new Stage();
// hide-end
import { BrowserWindow } from "stageroutine";

const browser = BrowserWindow({
  url: "../browser-demo/index.html",
  title: "Application demo",
  position: "center",
  width: 240,
  height: 86,
  // hide-start
  theme: { fontSizeKicker: "0.85rem" },
  // hide-end
  origin: "center",
});

// hide-start
stage.scene("Demo").with(browser);
stage.pause();
stage.mount("#stage");
// hide-end
```

Default size: 120 × 65 stage units. `interactive: false` disables page input (default: `true`).

Assign a new `url` to load another page:

```typescript
browser.url = "http://localhost:3000/settings";
```

## Navigation

Back and Forward use the browser’s Navigation API. Address updates read the iframe’s current URL. These controls work when the page shares the presentation’s protocol, host, and port. For other sites, the address shows the configured URL and history buttons stay disabled.

Reload opens the configured URL again. The address links to the displayed URL in a new tab.

Click outside the window to return keyboard control to the presentation.

## Embedding limits

The page must allow iframe embedding. Sites can block it with `X-Frame-Options` or CSP `frame-ancestors`. Blocked pages may remain on the loading screen. See [iframe embedding limits](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe).

See the [BrowserWindow API reference](../api/functions/BrowserWindow.md) for all options.
