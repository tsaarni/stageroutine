# BulletList

The `BulletList` component formats lists with customizable bullet markers and interactive row selection.

<DemoFrame src="/stageroutine/previews/bullet-list.html" />

```typescript preview="bullet-list.html"
// hide-start
import { Stage } from "stageroutine";
const stage = new Stage();
// hide-end
import { BulletList } from "stageroutine";

const list = BulletList([
  "Item 1",
  ["Sub-item A", "Sub-item B"],
  "Item 2",
], {
  x: "center",
  y: "center",
});
// hide-start
stage.scene("BulletList").with(list);
stage.pause();
stage.mount("#stage");
// hide-end
```

Pass nested arrays to create indented sub-items.

## Item Selection

Clicking or dragging bullet items interactively highlights selected rows and dims unselected items.

## Reveal

Items are visible by default. Pass `{ opacity: 0 }` to opt into reveal animations:

```typescript
const list = BulletList([
  "First bullet point",
  "Second bullet point",
  "Third bullet point",
], { opacity: 0 });

// Continuous staggered reveal in a single step
list.reveal();

// Or reveal step-by-step across presenter clicks
list.items.forEach((item) => {
  item.to({ opacity: 1, x: 0 }).duration(0.4);
  stage.pause();
});
```
