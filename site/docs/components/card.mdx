# Card

Cards group related content together on the stage.

<DemoFrame src="/stageroutine/previews/card.html" height={280} />

## Basic Usage

```typescript preview="card.html"
import { Card, Stage } from "stageroutine";

const stage = new Stage({ width: 800, height: 400 });

const card = Card("Card content", {
  x: "center",
  y: "center",
  width: 320,
  height: 160,
});

stage.scene("Card").with(card);
stage.pause();

stage.mount("#stage");
```

## Content Alignment

Cards center their content by default (`align: "center"`).
Use `align` to position content along the 9-point grid:

```typescript
const card = Card("System Status", {
  width: 320,
  height: 180,
  align: "top-left",
});
```

For all 9 alignment positions, see [Content Alignment](../building/coordinates#content-alignment).
