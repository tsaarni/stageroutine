# CodeBlock

The `CodeBlock` component formats code snippets with syntax highlighting and interactive line selection.

<DemoFrame src="/stageroutine/previews/code-block.html" />

```typescript preview="code-block.html"
// hide-start
import { Stage } from "stageroutine";
const stage = new Stage();
// hide-end
import { CodeBlock } from "stageroutine";

const code = CodeBlock('const x = 1;\nconsole.log(x);', {
  position: [80, 45],
  origin: "center",
});
// hide-start
stage.scene("CodeBlock").with(code);
stage.pause();
stage.mount("#stage");
// hide-end
```

Set `lang` (default: `"typescript"`) and `syntaxTheme` (default: `"vitesse-dark"`) for highlighting. Use `theme` for local StageRoutine tokens.

Assign `code.code` to replace the snippet. The change is restored by backward navigation. Token colors come from syntax highlighting.

## Line Selection

Clicking or dragging lines interactively highlights selected rows and dims unselected lines.
