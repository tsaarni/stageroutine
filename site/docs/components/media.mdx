# Media

StageRoutine includes components for visual media: `Image`, `Video`, and `Webcam`.

## Image

The `Image` component displays images on the stage.

<DemoFrame src="/stageroutine/previews/media.html" />

```typescript preview="media.html"
// hide-start
import { Stage } from "stageroutine";
const stage = new Stage();
// hide-end
import { Image } from "stageroutine";

const svg = `data:image/svg+xml;utf8,${encodeURIComponent(
  '<svg xmlns="http://www.w3.org/2000/svg" width="360" height="200" viewBox="0 0 360 200"><rect width="360" height="200" rx="8" fill="#1e293b"/><circle cx="180" cy="100" r="40" fill="#38bdf8"/></svg>',
)}`;

const image = Image(svg, {
  x: "center",
  y: "center",
  width: 360,
  height: 200,
});
// hide-start
stage.scene("Media").with(image);
stage.pause();
stage.mount("#stage");
// hide-end
```

## Sizing and Fit

`Image`, `Video`, and `Webcam` support CSS `object-fit` scaling via `fit`:

- `"contain"` (default for `Image` & `Video`): Scales to fit within bounds while preserving aspect ratio.
- `"cover"` (default for `Webcam`): Fills bounds completely, cropping overflow.
- `"fill"`: Stretches content to exact bounds.

## Video

`Video` wraps an HTML5 video element with playback options:

```typescript
import { Video } from "stageroutine";

const video = Video("/assets/recording.mp4", {
  x: "center",
  y: "center",
  width: 640,
  height: 360,
  muted: true,
  loop: true,
});
```

Clicking a video toggles playback interactively.

## Webcam

`Webcam` displays a live camera feed. Wrap it in a [`Frame`](./shapes.mdx#frame) to create a circular presenter bubble:

```typescript
import { Frame, paths, Webcam } from "stageroutine";

const cam = Frame(paths.circle(), Webcam({ mirror: true }), {
  x: 85,
  y: 80,
  size: 160,
  borderColor: "#38bdf8",
  strokeWidth: 2,
  active: true,
});
```
