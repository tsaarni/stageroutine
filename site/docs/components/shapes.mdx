# Shapes

StageRoutine provides geometric shape containers for diagrams and layout elements: `Circle`, `Pill`, and `Diamond`.

## Circle

The `Circle` component creates a circular node.

<DemoFrame src="/stageroutine/previews/circle.html" />

```typescript preview="circle.html"
// hide-start
import { Stage } from "stageroutine";
const stage = new Stage();
// hide-end
import { Circle } from "stageroutine";

const circle = Circle("Circle", {
  x: "center",
  y: "center",
  size: 180,
});
// hide-start
stage.scene("Circle").with(circle);
stage.pause();
stage.mount("#stage");
// hide-end
```

## Surface Variants

Shapes support three surface treatments via the `variant` option:

- `"surface"` (default): Translucent glass card with backdrop blur.
- `"ghost"`: Transparent background with border outline.
- `"solid"`: Opaque fill background.

```typescript
const outline = Circle("Ghost", {
  size: 120,
  variant: "ghost",
});
```
