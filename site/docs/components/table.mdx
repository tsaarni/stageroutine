# Table

The `Table` component formats structured tabular data with column alignment and row-level selection.

<DemoFrame src="/stageroutine/previews/table.html" />

```typescript preview="table.html"
// hide-start
import { Stage } from "stageroutine";
const stage = new Stage();
// hide-end
import { Table } from "stageroutine";

const table = Table({
  x: "center",
  y: "center",
  width: 520,
  headers: ["A", "B", "C"],
  rows: [
    ["1", "2", "3"],
    ["4", "5", "6"],
  ],
});
// hide-start
stage.scene("Table").with(table);
stage.pause();
stage.mount("#stage");
// hide-end
```

## Row Selection

Clicking or dragging table rows interactively highlights selected rows and dims unselected rows.

## Reveal

Rows are visible by default. Pass `{ opacity: 0 }` to opt into reveal animations:

```typescript
const table = Table({
  headers: ["Service", "Status"],
  rows: [
    ["Auth Gateway", "Operational"],
    ["Payment Engine", "Operational"],
  ],
  opacity: 0,
});

// Continuous staggered reveal in a single step
table.reveal();

// Or reveal step-by-step across presenter clicks
table.rows.forEach((row) => {
  row.to({ opacity: 1, x: 0 }).duration(0.4);
  stage.pause();
});
```
