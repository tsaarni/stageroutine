# TerminalBlock

The `TerminalBlock` component displays terminal command-line sessions with window controls and line selection.

<DemoFrame src="/stageroutine/previews/terminal-block.html" />

```typescript preview="terminal-block.html"
// hide-start
import { Stage } from "stageroutine";
const stage = new Stage();
// hide-end
import { TerminalBlock } from "stageroutine";

const terminal = TerminalBlock({
  x: "center",
  y: "center",
  width: 500,
  lines: [
    "$ command",
    "Output line 1",
    "Output line 2",
  ],
});
// hide-start
stage.scene("Terminal").with(terminal);
stage.pause();
stage.mount("#stage");
// hide-end
```

## Line Selection

Clicking or dragging terminal lines interactively highlights selected rows and dims unselected lines.
