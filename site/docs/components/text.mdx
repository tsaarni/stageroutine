# Text & Titles

StageRoutine provides typography components for stage presentations: `Title` for headings, `Text` for body copy, and `Kicker` for category micro-labels.

## Title

The `Title` component formats slide headlines.

<DemoFrame src="/stageroutine/previews/title.html" />

```typescript preview="title.html"
// hide-start
import { Stage } from "stageroutine";
const stage = new Stage();
// hide-end
import { Title } from "stageroutine";

const title = Title("Title", {
  x: "center",
  y: "center",
});
// hide-start
stage.scene("Title").with(title);
stage.pause();
stage.mount("#stage");
// hide-end
```

### Variants

`Title` supports three visual variants via `variant`:

- `"title"` (default): Bold display heading.
- `"hero"`: Larger display font for title slides.
- `"serif"`: Italic serif style.

```typescript
const hero = Title("Hero heading", { variant: "hero" });
const serif = Title("Editorial style", { variant: "serif" });
```

### Alignment

Typography components default to left alignment (`align: "left"`).
Use `align` to change text alignment:

```typescript
const centered = Title("System Status", { align: "center" });
const rightNote = Text("Confidential", { align: "right" });
```
