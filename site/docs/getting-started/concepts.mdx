# Basic Concepts

A StageRoutine presentation is built from four main parts:

![StageRoutine Concepts](/img/mental-model.svg)

## 1. Stage
The **Stage** is the presentation canvas and engine. It manages the `1920x1080` screen, hosts the background, and runs animations.

```typescript
const stage = new Stage();
```

## 2. Scenes
A **Scene** is a section of your presentation (like a slide). You specify which elements are visible using `.with(...)`:

```typescript
stage.scene("Architecture").with(title, codeBlock);
```

When changing scenes, elements shared between them smoothly animate to their new positions instead of disappearing.

## 3. Steps
A **Step** is a pause point. Calling `stage.pause()` groups all previous property changes into a click step:

```typescript
title.opacity = to(1);
stage.pause(); // Pauses playback until you press Next
```

## 4. Elements
An **Element** is an animated component on screen (`Title`, `CodeBlock`, `Table`, etc.). Each element wraps a real DOM node with reactive properties (`x`, `y`, `scale`, `opacity`).

```typescript
const title = Title("Hello StageRoutine", { x: "center", y: 40 });
```

## Comparison to Traditional Slides

| Slide Decks | StageRoutine | How It Differs |
|---|---|---|
| Presentation Window | **Stage** | Stays alive continuously across all scenes. |
| Slide | **Scene** | Elements persist between scenes when shared. |
| Click / Build | **Step** | Animates properties between pauses. |
| Text Box / Shape | **Element** | Reactive DOM node driven by GPU transforms. |
