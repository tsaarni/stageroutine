# Quick Start

Download the starter template and launch the dev server:

<Tabs groupId="package-manager">
  <TabItem value="pnpm" label="pnpm" default>

```bash
pnpm dlx giget gh:tsaarni/stageroutine/starter my-presentation
cd my-presentation
pnpm install
pnpm approve-builds
pnpm dev
```

  </TabItem>
  <TabItem value="npm" label="npm">

```bash
npx giget gh:tsaarni/stageroutine/starter my-presentation
cd my-presentation
npm install
npm run dev
```

  </TabItem>
  <TabItem value="bun" label="bun">

```bash
bunx giget gh:tsaarni/stageroutine/starter my-presentation
cd my-presentation
bun install
bun dev
```

  </TabItem>
  <TabItem value="yarn" label="yarn">

```bash
yarn dlx giget gh:tsaarni/stageroutine/starter my-presentation
cd my-presentation
yarn install
yarn dev
```

  </TabItem>
</Tabs>

The dev server provides two views:

- **Presentation**: `http://localhost:5173/` - live presentation with hot-reloading as you edit `src/main.ts`.
- **Presenter Console**: `http://localhost:5173/presenter.html` - dual-screen console with speaker notes, upcoming step previews, and a live timer.

## Controls

| Key | Action |
|---|---|
| `→` / `Space` / `PageDown` | Next step |
| `←` / `PageUp` | Previous step |
| `Shift+→` / `Shift+←` | Next / Previous scene |
| `Home` / `End` | First / Last step |
| `L` | Toggle laser pointer |

## Building Static Files

Build static files that run without a dev server:

<Tabs groupId="package-manager">
  <TabItem value="pnpm" label="pnpm" default>

```bash
pnpm build
```

  </TabItem>
  <TabItem value="npm" label="npm">

```bash
npm run build
```

  </TabItem>
  <TabItem value="bun" label="bun">

```bash
bun run build
```

  </TabItem>
  <TabItem value="yarn" label="yarn">

```bash
yarn build
```

  </TabItem>
</Tabs>

The output is written to `dist/`, containing both `index.html` and `presenter.html`. It is ready to upload to any static web host.
